# Published figure references

These six images are copies of the published documentation figures in `docs/src/images/`.
They are retained for visual comparison with independently reproduced results.

The calculated Figure 4C Bray-Curtis dissimilarity is uploaded separately as
`darone-bray-curtis-full` after the full ten-year global simulations finish.

The short `Pkg.test()` simulations use synthetic inputs to verify builds,
execution, and NetCDF output. They also run the beginner plotting example;
their short-run results are not manuscript reproductions.
