# DarOne figure checks

- `documentation/` contains the **six original PNG images** used in the published documentation. They are copied byte-for-byte from `docs/src/images/` and serve as visual references.
- `generated/` contains plots calculated from the CI integration-test outputs. The bottle, Bray-Curtis, and nitrogen-fixer checks use the same quantities as the corresponding documentation figures, with `_ci` in their filenames to distinguish the short-run checks. The beginner figure is generated by its existing example.

The CI uses synthetic inputs, with 56 iterations for the seven-day bottle experiment and 12 iterations for the other cases. Full scientific reproduction of the global Bray-Curtis figure uses the original reference DARWIN dataset and 20-year simulations; the nitrogen-fixer figure uses a five-year simulation and the final-year mean. The composite figures also incorporate explanatory graphics. The original notebooks under `ipython_notebooks/` are useful plotting references for the bottle and Bray-Curtis analyses.
